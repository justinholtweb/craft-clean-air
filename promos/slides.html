Operators

Operators that fit the value

Clean Air doesn’t ask what class a field is. It asks what shape its value is — so a plain text field, a URL, an email, a CKEditor body, a variant SKU and an address line all get the same operators without any of them being listed anywhere.

Text
is, is not, contains, doesn’t contain, starts with, ends with, is one of, is none of, is empty, is not empty
Number & money
=, ≠, >, ≥, <, ≤, is between, is empty, is not empty
Date
is on, is before, is after, is between, is in the last, is in the next, is empty, is not empty
Dropdown
is, is not, is one of, is none of, is empty, is not empty
Relation
is assigned, is not assigned, has at least, has at most, is empty, is not empty
Switch
is on, is off

Migration

A way out of
CP Filters

CP Filters was discontinued in April 2024 and never made the jump to Craft 5. Clean Air reads its table directly and brings the filters across.

  • Nothing is written until you press Import
  • CP Filters itself is left exactly as it is
  • Every condition it can’t carry is named, not dropped quietly
Seven legacy filters previewed. The amber row lost a deleted field; the red one uses an element type that no longer exists — both are reported before anything is imported.
